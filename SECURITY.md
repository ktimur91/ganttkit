# Security policy

## Supported versions

Only the latest published version of `ganttkit` receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub security advisories](https://github.com/ktimur91/ganttkit/security/advisories/new).
You will get an answer within a week.

Releases are published from GitHub Actions with npm provenance, so you can check that a package
version was built from this repository: `npm audit signatures`.
